# Examples

These minimal TypeScript applications exercise csslit through the framework's normal Vite build:

- [React](./react)
- [Preact](./preact)
- [Solid](./solid)
- [Vue](./vue)
- [Octane](./octane)
- [React Router Framework Mode](./react-router)
- [MDX](./mdx)
- [Astro](./astro)

Run an example from the repository root:

```sh
vp run example-react#dev
vp run example-react#build
```

Replace `react` with `preact`, `solid`, `vue`, `octane`, `react-router`, `mdx`, or `astro`.
